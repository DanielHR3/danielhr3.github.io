## 🎯 Sobre el portfolio

Portfolio personal diseñado para presentar mi trabajo, habilidades y trayectoria profesional. Sin frameworks ni dependencias de JavaScript: HTML, CSS y un script mínimo para las animaciones al hacer scroll.

## 📄 Secciones

| Sección | Contenido |
|---|---|
| **Hero** | Foto, nombre, badge de disponibilidad y CTAs |
| **Proyectos** | Cards con capturas reales, stack y enlace a la demo |
| **Stack** | Tecnologías agrupadas por área, con el uso que les doy |
| **Experiencia** | Timeline de roles, formación y cursos |
| **Contacto** | Correo, LinkedIn, GitHub y CV en español e inglés |

## 🛠️ Tecnologías

- **HTML5** — Estructura semántica
- **CSS3** — Variables custom, animaciones, glassmorphism, grid
- **JavaScript** — IntersectionObserver para animaciones on-scroll (respeta `prefers-reduced-motion`)
- **Google Fonts** — Space Grotesk + Inter
- **GitHub Pages** — Hosting gratuito

## 🎨 Diseño

- Paleta: `#0a0a0a` (fondo) + `#6B8E23` (accent verde olivo) + `#A67B5B` (warm)
- Tipografía: **Space Grotesk** (headings) + **Inter** (body)
- Efectos: grid background y glow en hover

```bash

cd danielhr3.github.io
# Abre index.html en tu navegador preferido
# O usa Live Server en VS Code
```
