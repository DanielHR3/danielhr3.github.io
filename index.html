En producción · PWA offline-first

Pañuelo sin efecto

Arbitraje y gestión de ligas de flag football. El árbitro anota desde el celular aunque no haya señal en el campo: las jugadas se guardan en IndexedDB y se sincronizan al volver la conexión. El marcador no se edita, se reconstruye a partir de eventos inmutables, así que cada partido queda auditable. Incluye panel para dueños de liga y modo de arbitraje sin cuenta.

Cómo trabajo

01

Primero la historia de usuario

No se desarrolla nada sin historia de usuario y criterios de aceptación. Las pruebas se escriben contra esos criterios.

02

El humano define, el agente ejecuta

Uso agentes de IA para implementar, pero un módulo solo está terminado cuando pasan build, lint y pruebas y una persona revisó el diff.

03

Contrato antes que código

La API se define en OpenAPI y el frontend consume un cliente generado. Jest, Supertest, Vitest y Playwright cubren el resto.

04

Seguridad y documentación

Auditoría de dependencias, revisión contra OWASP Top 10, bitácora de desarrollo y decisiones de arquitectura por escrito.
